# Java grid interconnection in IndoTERM-E

Discussion paper for the team (draft v1, 13 October 2026): how the idea of connecting the Java-Bali grid to the outer islands could be simulated with IndoTERM-E, in a static and a dynamic set-up.

Open `index.html` in a browser. The page is self-contained: figures are embedded, equations are rendered with MathML, and it has a contents sidebar, links from the `[C..]` tags to the numbers register in Appendix C, and a light/dark switch.

Source: `IndoTERM-E_Java_grid_interconnection_team_discussion_v1.docx` (converted with pandoc).

Nothing has been simulated yet. This is a basis for discussion, not a result.
